# Despliegue en GitHub Pages

## Objetivo
Publicar la documentación del proyecto para que pueda consultarse desde un navegador.

## Preparación
1. Guardar los cambios en el repositorio Git.
2. Instalar las dependencias del proyecto.
3. Generar la versión de producción de Docusaurus.

## Generación del sitio
Ejecutar desde la raíz del proyecto:

    npm run build

## Publicación
Configurar GitHub Pages para publicar los archivos generados siguiendo la configuración del repositorio.

## Verificación
Abrir la URL publicada y comprobar que las páginas y los enlaces funcionan.
