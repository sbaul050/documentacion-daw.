# Introducción al proyecto

## Sistema de gestión de tareas

Este proyecto consiste en desarrollar una aplicación para gestionar tareas y proyectos de forma sencilla.

### Objetivos
- Crear y organizar tareas.
- Asignar tareas a usuarios.
- Consultar el estado de cada tarea.
- Facilitar el seguimiento de los proyectos.

### Tecnologías
- Frontend: React.
- Backend: Node.js.
- Base de datos: PostgreSQL.
- Documentación: Docusaurus.
