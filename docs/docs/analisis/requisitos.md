# Análisis de requisitos

## Requisitos funcionales
- RF01: El sistema permitirá registrar usuarios.
- RF02: Los usuarios podrán crear, modificar y eliminar tareas.
- RF03: Cada tarea tendrá título, descripción, prioridad y estado.
- RF04: Se podrán asignar tareas a usuarios.

## Requisitos no funcionales
- RNF01: La aplicación deberá ser accesible desde un navegador web.
- RNF02: Las contraseñas se almacenarán de forma segura.
- RNF03: La interfaz deberá ser intuitiva y adaptable.
