# Pruebas: análisis de caja blanca

## Objetivo
Verificar el funcionamiento interno de las principales funciones del sistema.

## Casos de prueba

### CP01: Crear una tarea
Entrada: título válido y descripción.
Resultado esperado: la tarea se guarda correctamente.

### CP02: Validar campos obligatorios
Entrada: título vacío.
Resultado esperado: el sistema muestra un mensaje de error.

### CP03: Cambiar el estado
Entrada: tarea pendiente y nuevo estado completado.
Resultado esperado: el estado se actualiza correctamente.

## Criterio de aceptación
Todas las pruebas deberán finalizar con el resultado esperado.
