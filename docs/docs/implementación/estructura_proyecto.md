# Implementación: estructura del proyecto

## Organización del código

- src/: código fuente de la aplicación.
- src/components/: componentes de interfaz.
- src/services/: comunicación con la API.
- server/: lógica del servidor.
- tests/: pruebas automatizadas.
- docs/: documentación técnica.

## Desarrollo
El frontend se implementará con React y el backend con Node.js.

## Control de versiones
Se utilizará Git para gestionar los cambios y GitHub para alojar el repositorio.
